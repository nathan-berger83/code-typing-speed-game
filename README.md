## What Is Code Typing Challenge?

Rather than drilling you on ordinary paragraphs, this project hands you actual code to reproduce keystroke by keystroke. Each round is built around a genuine snippet, so anyone learning to program, or already working as a developer, can build keyboard fluency against syntax that feels familiar.

Snippets span a set of widely used languages and frontend tools: Python, JavaScript, TypeScript, React, Go, Rust, and SQL. While you type, the screen keeps a running count of character accuracy and words per minute, which means every finished challenge gives you a read on both how fast you went and how cleanly you hit the keys.

## Highlights

- Every challenge is drawn from real programming code, not filler text.
- Content libraries for Python, JavaScript, TypeScript, React, Go, Rust, and SQL.
- Correct and incorrect keystrokes are flagged visually the moment they happen.
- Words per minute is calculated live for the current session.
- Accuracy is tracked continuously as you move through a snippet.
- Runs entirely in the browser; there is no desktop app to install.
- Frontend stack: React 18, Babel Standalone, and CSS.
- Suited to coding drills, hands-on learning, and general typing improvement.

## How to Play

1. Open either the hosted build or your local copy.
2. Pick one of the supported languages or snippet categories.
3. Start typing the code shown on screen.
4. Watch the live character feedback and fix slips as they appear.
5. Check your WPM and accuracy once the challenge is finished.
6. Run another language or snippet to see how your numbers compare.
